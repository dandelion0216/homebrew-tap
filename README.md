# dandelion0216/homebrew-tap

Homebrew formulae by dandelion0216.

## ghostty-tailor

A GUI for tailoring your [Ghostty](https://ghostty.org) configuration. See [ghostty-tailor](https://github.com/dandelion0216/ghostty-tailor).

```sh
brew install dandelion0216/tap/ghostty-tailor
```

macOS only for now. The app is built from source during installation (Go is installed automatically as a build dependency).
